# ML_LLM — kombinera ML-artefakt och generativ AI

Spegel av det globala Grok-skill:et `ml-llm-kombination`.

**Syfte:** låta klassisk ML (prognos, klass, avvikelse) producera låsta tal och låta LLM:en förklara, orkestrera och skriva — inte räkna.

## Filer

- [SKILL.md](SKILL.md) — arbetsregler, beslutsträd, tre mönster, anti-mönster
- [references/aktorer-processer.md](references/aktorer-processer.md) — aktörer, plattformar och länkar (compound AI, RAG, HuggingGPT, MLflow, DSPy, Hugging Face, JFrog m.fl.)

## Global kopia

## Kärnregel

```
ekonomisystem → regler/nyckeltal → ML-artefakt → RAG → LLM-text → controller låser
```

Officiell tertialsiffra kommer inte från chatten.
