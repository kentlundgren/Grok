# IDE – Cursor, Antigravity och gränsen mot agentapparna

Live-sida: [https://kentlundgren.github.io/Grok/aktuellt/IDE/](https://kentlundgren.github.io/Grok/aktuellt/IDE/)

Sammanställning från ett samtal 9 oktober 2026. Uppslaget var Aslams inlägg den 9 oktober 2026, med fyra rutor: VS Code, Antigravity, Codex och Cursor. Därefter svarade Kent att han arbetat med tre av de fyra, inte Antigravity, och ville se hur de förhåller sig. Sedan jämfördes Cursor och Google Antigravity. Sidan går vidare till vad en IDE är, hur de två editorerna förhåller sig till varandra, vilka andra editorer som konkurrerar, och varför Claude Code, Claude Cowork och Codex-appen inte är IDE:er i strikt mening.

Statisk sida, relativa länkar, ingen build. Samma mapp kan ligga på GitHub Pages.
