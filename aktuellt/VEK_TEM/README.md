# Samma fråga, nya modeller

- **Live:** [https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/)

Statisk webbsida (HTML, CSS, JavaScript, ingen build) som svarar på en återkommande fråga: **hur ser man en organisation så att man kan styra, planera och följa upp den?** Samma tema som blogginlägget [Samma fråga, nya modeller](https://controllerutangranser.wordpress.com/2026/10/16/samma-fraga-nya-modeller/) (16 oktober 2026) och en kortare [LinkedIn-artikel](https://www.linkedin.com/pulse/samma-fr%C3%A5ga-nya-modeller-kent-lundgren-jmkee/). Sidan är den utökade versionen med källor, diagram och uppgiftskontroll.

Mappen heter `VEK_TEM` i repot eftersom jämförelsen utgår från **VEK** (verksamhet, ekonomi, kompetens), **TEM** (teknik, ekonomi, miljö) och **balanserat styrkort** – men innehållet handlar om modeller i stort, inte bara om de tre namnen.

## Vad sidan innehåller

Länkarna går till avsnitten på live-sidan.

| Avsnitt | Innehåll |
| --- | --- |
| [Kort svar](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#kortsvar) | Flera perspektiv än ekonomi, managementmode, privat/offentligt, gemensamma frågor. |
| [Tre sätt](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#tre-satt) | VEK, TEM och balanserat styrkort – med tabell och Diagram 1. VEK beskrivs utifrån en statlig myndighet i källan (läsaren kan känna igen exemplet; sidan säger **myndigheten** där det räcker). |
| [Verksamhetsringen](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#verksamhetsringen) | Egen variant av balanserat styrkort: verksamhetsförst, medurs till finansiellt utfall, controller i centrum. |
| [Tre steg](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#hjulet) | Styrning, planering och uppföljning – egen uppdelning, Diagram 2 (VEK i praktiken). |
| [Modeller och mode](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#moden) | Abrahamson, tidslinje, [balanserat styrkort idag](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#h-bsc-idag) (popularitet, kritik, andra ramverk). |
| [Privat och offentligt](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#privat-offentligt) | Tabell 2 utifrån källor. |
| [Fyra frågor](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#fyra-fragor) | Checklista inför nästa modell (egen). |
| [Källor](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/#kallor) | Harvardstil med hämtdatum; fakta jämförda mot original där det gått. |

Faktauppgifter är markerade mot källor. Jämförelser, diagramkopplingar, Verksamhetsringen, tidslinje och frågelista är **egna sammanställningar** och står så på sidan.
