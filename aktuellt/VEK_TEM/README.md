# Samma fråga, nya modeller

Undertitel: VEK, TEM och balanserat styrkort.

Live-sida: [https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/](https://kentlundgren.github.io/Grok/aktuellt/VEK_TEM/)

Lokal mapp: `C:\Users\kentl\OneDrive\AI\Grok\aktuellt\VEK_TEM`

Bakgrund till ett kortare inlägg på LinkedIn. Sidan jämför tre sätt att se en organisation för att kunna styra, planera och följa upp den: VEK (verksamhet, ekonomi och kompetens, Polismyndigheten), TEM (teknik, ekonomi och miljö) och balanserat styrkort. Den tar också upp varför nya modeller kommer när den förra har blivit vanlig (managementmode), och om samma tankemodell fungerar i privat och offentlig verksamhet.

Statisk sida, relativa länkar, ingen build. Samma mapp kan ligga på GitHub Pages.
