# Endimensionell analys

- **Live:** [https://kentlundgren.github.io/Grok/aktuellt/endimensionell_analys/](https://kentlundgren.github.io/Grok/aktuellt/endimensionell_analys/)

Interaktiv visualisering av tre satser från envariabelanalys:

- medelvärdessatsen
- satsen om mellanliggande värden
- extremvärdessatsen

Öppna sidan:

https://kentlundgren.github.io/Grok/aktuellt/endimensionell_analys/

Dra i ändpunkterna a och b. Funktionen |x| visar vad som händer när derivatan saknas. Under mellanliggande värden och extremvärde finns motexempel: språng och öppet intervall.

En enda fil, [index.html](index.html), utan byggsteg.
