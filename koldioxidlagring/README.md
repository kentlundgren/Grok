Anteckningar från SGU-föredraget om geologisk lagring, plus en enkel BECCS-kalkyl.

## Vad mappen täcker

- Varför lagring ska ske djupare än 800 meter (superkritiskt tillstånd)
- Uppskattad kostnad per kWh för bioenergi med avskiljning och lagring
- Varför svensk lag bara tillåter lagring till havs
- De två undersökta områdena och vad kartorna faktiskt visar
- Arnagergrönsanden och borrningarna i Skåne

## Teknik

Statisk HTML med Tailwind CSS via CDN. Ingen build.
