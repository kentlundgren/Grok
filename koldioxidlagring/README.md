Anteckningar från SGU-föredraget, BECCS-kalkyl och nordisk jämförelse.

## Vad mappen täcker

- Varför lagring ska ske djupare än 800 meter
- Uppskattad kostnad per kWh för bioenergi med avskiljning och lagring
- Hur långt Norge och Danmark kommit, och vad det kostar där
- Varför svensk lag bara tillåter lagring till havs
- De två undersökta områdena och vad kartorna visar

## Teknik

Statisk HTML med Tailwind CSS via CDN. Ingen build.
