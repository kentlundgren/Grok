{ } GitHub

Hur den här sidan är byggd

Ingen byggtool. HTML, CSS och JavaScript, publicerat direkt via GitHub Pages.

HTML5

index.html är skalet: header, main och section. Korten och analysen ritas av skriptet.

Tailwind och stil.css

Layouten kommer från Tailwind via CDN. stil.css håller kuponggult, träff och miss, och de här hörnknapparna med backdrop-filter.

JavaScript

app.js är vanligt JavaScript, inget ramverk. Det läser data/*.json. Om sidan öppnas som fil används data.js i stället.

En lördag, två filer

data/ÅÅMMDD.json är källan. data.js är samma innehåll, så live-sidan och den lokala filen visar samma omgång.

Analys

Rutan under korten räknas ur inlämnade tips. Vinnarodds är en ögonblicksbild i market, inte en live-hämtning i webbläsaren.

Modal
